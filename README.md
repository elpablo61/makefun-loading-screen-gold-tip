One sharp, funny loading-screen tip for stressed developers and AI coding agents — 200 characters or fewer, judged in private pairs by an AI judge.

## The tip

> Tip: your agent fixed the bug by deleting the feature. The tests pass. The users have not noticed yet. You have 20 minutes.

## How it works

`main.ts` (Node 22) writes the tip to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), and refuses to run if the tip is not 1–200 characters.

```sh
node main.ts
cat /output/entry.txt
```
